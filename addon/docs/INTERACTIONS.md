# Переходы палитры, кнопки и иконки

`src/palette-transition.ts` сохраняет прежний градиент перед сменой палитры,
затем накладывает `.colorize-palette-background` и плавно убирает его за 920 мс.
Сами переменные записываются один раз. При быстрой смене цвета следующий переход
начинается с промежуточного состояния предыдущего. Слой не перехватывает клики,
удаляется по завершении или при уходе со страницы. `prefers-reduced-motion`
отключает анимацию. Определения фонов принадлежат CSS темы Colorize-2.

`src/wheel-icon-tint.ts` читает `--ym-controls-color-secondary-text-enabled`,
подбирает составной CSS-фильтр, включая `hue-rotate`, и сохраняет его в
`--colorize-wheel-icon-filter`. Результаты кэшируются для 32 цветов.
CSS темы ограничивает применение двумя действиями колеса; остальные изображения
не перекрашиваются. Одного hue-rotate недостаточно для точного изменения насыщенности
и яркости, поэтому используются также invert, sepia, saturate, brightness и contrast.

Цвета SVG, hover/focus/active/disabled и фон кнопок находятся в
`Colorize-2/src/pulsecolor-controls.css` и `Colorize-2/src/styles.css`.
Автозатемнение требует одновременно решения Core и CSS темы.

Проверка: `pnpm test:ui` и `pnpm test:contrast` из корня Colorize2Core.
Проверяются сохранение фона, фокус, disabled, отсутствие квадрата на Play,
переходы и reduced motion, яркость радиального центра и тёмных краёв.
